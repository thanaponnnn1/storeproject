# หน้าบ้าน (Next.js)

## รันบนคอมพิวเตอร์

```bash
pnpm install
pnpm dev          # เปิดที่ http://localhost:3001
```

ต้องมี backend รันอยู่ที่ `http://localhost:3009` ด้วย (ตั้งค่าใน `.env.local`)

---

## 📱 ใช้กล้องมือถือสแกนบาร์โค้ด

**iPhone/iPad จะไม่ยอมเปิดกล้องให้เว็บที่ไม่ใช่ https** (กฎความปลอดภัยของ iOS)
เปิดผ่าน `http://192.168.x.x:3001` จะสแกนไม่ได้ ต้องทำแบบนี้:

### 1. สร้างใบรับรอง (ทำครั้งเดียว / ทำใหม่เมื่อเปลี่ยน WiFi)

```bash
pnpm cert
```

สคริปต์จะหา IP ของคอมในวง WiFi ให้เอง แล้วสร้างใบรับรองที่ครอบคลุม IP นั้น
— **สำคัญ**: ถ้าใบรับรองมีแต่ `localhost` มือถือจะเปิดไม่ได้

### 2. เปิด firewall ให้มือถือเข้าถึงได้ (ทำครั้งเดียว)

Windows บล็อกการเชื่อมต่อจากเครื่องอื่นโดยปริยาย เปิด PowerShell **แบบ Run as
Administrator** แล้วรัน:

```powershell
New-NetFirewallRule -DisplayName "Store dev 3001" -Direction Inbound `
  -LocalPort 3001 -Protocol TCP -Action Allow -Profile Private
```

> `-Profile Private` = เปิดเฉพาะเน็ตบ้าน/ร้านที่ตั้งเป็น Private ไม่เปิดตอนต่อ WiFi
> สาธารณะ · เลิกใช้แล้วลบด้วย `Remove-NetFirewallRule -DisplayName "Store dev 3001"`

### 3. รันแบบ https

```bash
pnpm dev:https
```

### 4. เปิดจาก iPhone

ต่อ WiFi **วงเดียวกับคอม** แล้วเปิด Safari ไปที่ที่อยู่ที่ `pnpm cert` บอก เช่น:

```
https://192.168.1.37:3001
```

### 5. ยอมรับใบรับรอง

Safari จะเตือน "การเชื่อมต่อนี้ไม่ใช่แบบส่วนตัว" เพราะใบรับรองสร้างเอง
กด **แสดงรายละเอียด → เข้าชมเว็บไซต์นี้** (ปลอดภัยเพราะเป็นเครื่องเราเอง ในวง WiFi เรา)

### 6. อนุญาตกล้อง

เข้าเมนู **สแกน** → กด **เริ่มสแกน** → Safari ถามขอใช้กล้อง → กด **อนุญาต**

### 7. เพิ่มลงหน้าจอโฮม (ทำครั้งเดียว ใช้สะดวกขึ้นมาก)

ใน Safari กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** จะได้ไอคอนเปิดเหมือนแอป
ไม่มีแถบที่อยู่มากินพื้นที่จอ

## ยิงอะไรได้บ้าง

| ยิง | ได้อะไร |
|---|---|
| บาร์โค้ดสินค้า (EAN-13 จากโรงงาน) | ชื่อ ยอดคงเหลือ ราคา |
| บาร์โค้ดของลัง/มัด | ยอดคงเหลือแปลงเป็นหน่วยนั้นให้ (120 เส้น = 12 มัด) |
| QR ที่ร้านพิมพ์เอง | เหมือนบาร์โค้ดปกติ (สำหรับของที่ไม่มีบาร์โค้ดโรงงาน) |
| Serial บนตัวเครื่อง (แอร์/ตู้เย็น) | ซื้อวันไหน ใครซื้อ **ประกันเหลือกี่วัน** |

**ของที่ไม่มีบาร์โค้ดโรงงาน** (เหล็กเส้น ท่อ ปูน): เข้าหน้าสินค้า → หัวข้อบาร์โค้ด →
กด **แสดง QR สำหรับพิมพ์** → พิมพ์ไปแปะที่ชั้นวาง

---

## ถ้ากล้องใช้ไม่ได้

หน้าสแกนมีช่อง **"หรือพิมพ์รหัส/serial ด้วยมือ"** อยู่ล่างกล้องเสมอ —
บาร์โค้ดเลอะ ฉลากขาด หรือกล้องเสีย ก็ยังทำงานต่อได้
